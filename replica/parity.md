## 3. Differentiators & Solved Gaps (Not in Original)

The following 9 features were created specifically to fix major community issues documented in `replica/feedback.md` and `replica/fixes.md`:

1. **Local-First Custom Playlists (Fix #904)**: Users can create, edit, and organize custom playlists immediately without logging into a Google/YouTube Music account.
2. **M3U / M3U8 Playlist Export & Import**: Standard playlist file exchange format supported natively for export to third-party audio software and car audio.
3. **Phonetic Romanization & Transliteration (Fix #364 & #439)**: Dynamic Romaji and Hangul transliterations rendered beneath Asian character lyrics, plus dual-line English translations.
4. **LRC File Disk Exporter (Fix #909)**: Direct 1-click `.lrc` timestamped file downloader for digital audio players (DAPs) and car infotainment units.
5. **Granular Cache Manager (Fix #899)**: Per-track file size breakdown with single-track eviction buttons, preventing local disk bloat without forcing a full data wipe.
6. **External System Browser OAuth (Fix #903)**: Loopback receiver (`127.0.0.1:8901`) spawns system Chrome/Edge/Firefox, eliminating outdated embedded WebView crashes.
7. **3-State Loop Repeat-One Button (Fix #900)**: Complete loop cycling (`Off` -> `All` -> `One`) with visual badge.
8. **Pitch-Preserved Variable Speed Control (Fix #890)**: $0.5\times$ to $2.0\times$ tempo adjustment with audio pitch preservation (`preservesPitch = true`).
9. **Native Responsive HiDPI Windowing (Fix #884 & #913)**: True full-screen borderless windowing with fluid scaling down to 390px mobile viewport width.
